# 📋 Карточка сотрудника Smartway

Userscript для автоматического извлечения данных сотрудника из системы Smartway и формирования готовой карточки для копирования.

## 🎯 Возможности

- **Автоматический парсинг** страницы сотрудника в Smartway
- **Три формата карточки**: Стандартная, ЖД, Страховка
- **Горячие клавиши** для быстрого вызова (Ctrl+1, Ctrl+2, Ctrl+3)
- **Копирование в буфер** одним кликом
- **Автоматические обновления** через GitHub
- **Кроссбраузерность**: Chrome, Яндекс Браузер, Firefox, Edge

## 📦 Установка

### Требования
- Браузер: Chrome, Яндекс Браузер, Firefox или Edge
- Расширение: [Tampermonkey](https://www.tampermonkey.net/) (установить из магазина браузера)

### Шаги установки

1. **Установите Tampermonkey**
   - Chrome: [Chrome Web Store](https://chrome.google.com/webstore/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo)
   - Яндекс Браузер: через каталог расширений Яндекса
   - Firefox: [Firefox Add-ons](https://addons.mozilla.org/ru/firefox/addon/tampermonkey/)

2. **Установите скрипт**
   - Перейдите по ссылке: https://raw.githubusercontent.com/HorrorStoryy/smartway-card/main/smartway-card.user.js
   - Tampermonkey автоматически откроет окно установки
   - Нажмите **"Установить"**

3. **Готово!** Откройте страницу сотрудника в Smartway — зелёная кнопка 📋 появится справа вверху.

## 🚀 Использование

### Кнопка на странице
На любой странице сотрудника (`/employeePage/*`) справа вверху появляется зелёная круглая кнопка **[📋]**.

### Панель карточки
При клике на кнопку открывается панель с тремя кнопками:
- **📋 Стандартная** — полная карточка с паспортом РФ (для граждан РФ) или загранпаспортом (для иностранцев)
- **🚄 ЖД** — карточка для бронирования ж/д билетов
- **🛡️ Страховка** — карточка для оформления страховки (с email)

### Горячие клавиши
- **Ctrl+1** — открыть панель и сгенерировать стандартную карточку
- **Ctrl+2** — открыть панель и сгенерировать ЖД карточку
- **Ctrl+3** — открыть панель и сгенерировать карточку страховки

### Копирование
После генерации карточки нажмите кнопку **"📋 Копировать"** — текст скопируется в буфер обмена с сохранением всех переносов строк.
